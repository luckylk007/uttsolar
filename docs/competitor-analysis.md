## Key Patterns Observed

### Header / Navigation
- Top utility bar with scheme name (PM Surya Ghar), phone, WhatsApp
- Primary CTA: "Get Free Quote" / "Book Site Survey"
- Mobile: sticky header with call + WhatsApp + hamburger

### Homepage Sections (Common)
1. Hero with value proposition + dual CTA
2. Subsidy/scheme banner
3. Service type cards (Residential / Commercial / Industrial)
4. System type (On-grid / Off-grid / Hybrid)
5. Calculator or savings preview
6. Installation process steps
7. Why choose us / trust signals
8. Service areas / locations
9. FAQ accordion
10. Final CTA band

### Calculator Patterns
- Monthly bill slider + quick amount buttons
- System type toggle
- Results: recommended kW, savings, subsidy, payback
- Post-result lead capture (non-blocking)

### Location SEO Architecture
- `/locations/` hub → district archive → `{location}-solar-service`
- District pages list major towns (not just HQ)
- Local FAQs per location
- Breadcrumbs + internal links to services/calculator/subsidy

### Trust Elements (Genuine Only)
- Years in business, project photos, warranty info
- Authorized brand partnerships (when verifiable)
- Process transparency, after-sales AMC
- **Avoid**: fabricated review counts, fake certifications

## UTTsolar Differentiation Strategy

1. **Uttarakhand-first IA** — all 13 districts with commercially relevant towns
2. **Verified subsidy engine** — configurable PM Surya Ghar rates (special category state: ₹33k/₹19.8k per kW)
3. **Hindi/English** — URL-based locale (`/` and `/hi/`) with hreflang
4. **Lead-gen calculator** — results first, optional form after
5. **Unique local content** — geography, DISCOM (UPCL), net metering context per location
6. **Performance-first** — minimal JS, static generation, optimized images
7. **Security-by-default** — validated forms, rate limiting, CSP headers
